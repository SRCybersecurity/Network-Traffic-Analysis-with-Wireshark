# ELEVATELABS_TASK5
## Network traffic analyses using Wireshark
Deliverables: A packet capture (.pcap) file and a short report of protocols identified along with scanned results screenshots.

---
## 🎯 Objective
Capture live network packets and identify basic protocols and traffic types.

## 🛠️ Tools
Wireshark (free).

## 📌 Steps
Wireshark is the most common tool for capturing and analysing network traffic. Here's given following steps: <br>
Task Breakdown and Instructions
Start capturing on your active network interface.

---
### 1.	Open Wireshark.
---
### 2.	Select your active network interface (usually "Wi-Fi" or "Ethernet" depending on your connection).
---
### 3.	Click the blue shark fin icon (top-left) to start the capture.
---
### 4. Browse a website or ping a server to generate traffic.
•	Visit a website like https://www.scanme.nmap.org </br>
•	On a terminal/command prompt and run: ping google.com

--- 
### 5. Stop capture after a minute
•	Wait about 60 seconds.  </br>
•	Return to Wireshark and click the red square icon to stop the capture. 

---

In the top filter bar, try filters like

### 6. Identify at least 3 different protocols in the capture.
You should see: <br>
• DNS – used for resolving domain names <br>
• TCP – transport layer protocol used by HTTP, HTTPS <br>
• HTTP – if you visited an unencrypted website <br>
• HTTPS – encrypted web traffic (shows as TLS) <br>
• ICMP – if you used ping.

---
### 7. Export the capture as a .pcap file.
1.	Go to File > Save As... <br>
2.	Choose a location and name, and save it as .pcapng or .pcap.
